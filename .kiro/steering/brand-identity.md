# Kiro Essentials — Brand Identity Steering

_Last updated: 2026-10-08_

Read `_invariants.md` first.

This steering preserves the existing DUIT visual language while the workshop product idea is still undefined.

## Brand character

The UI should feel:

- modern;
- refined;
- highly legible;
- fresh;
- cohesive;
- professional;
- calm and clear.

Brand expression must support usability rather than compete with it.

## Logo

- Reuse approved DUIT logo assets already present in the repository.
- Do not redraw, distort, reconstruct, or arbitrarily recolor the logo.
- Use the appropriate existing light/dark variant for the background.

## Typography

Corporate direction:

```txt
Logo: Quantify Regular
Primary: Montserrat
Secondary/body: Source Sans Pro
```

Before changing typography, inspect and reuse the repository's existing font loading and tokens.

## Core colors

```txt
Space Blue  #101D29
Azure Blue  #2EAEE4

Supporting
#2357A2
#22244E
#398DCB
#18ACC7
```

Use Space Blue and Azure Blue as the primary recognizable brand anchors.

Do not force semantic success, warning, error, or destructive states into the brand blue palette.

## Graphic language

Blue-to-cyan gradients and DUIT-inspired geometric motifs may be used selectively for:

- authentication branding;
- headers;
- empty/onboarding surfaces;
- illustrations or restrained decorative backgrounds.

Do not apply gradients by default to every button, field, card, or control.

## UI rule

For visible changes:

1. inspect current tokens, fonts, assets, and primitives;
2. reuse existing implementation where practical;
3. preserve hierarchy, legibility, accessibility, and responsive behavior;
4. avoid an unrelated whole-product redesign.
